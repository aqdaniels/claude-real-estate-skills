# The lease box / buy box

Capture what the user said; fill the rest with these defaults and mark each as user-stated or default in the report.

| Criterion | Ask if missing? | Default |
|---|---|---|
| Geography | Yes | — |
| Lease, buy, or both | Yes | Both, if the user says "find spaces" and mentions turning something into a use |
| Use / concept | Yes | — (for restaurants: service style, seats, bar, drive-thru, patio) |
| Size range | No | Restaurants: QSR/coffee 800–2,000 SF; fast-casual 1,800–3,200; full-service 3,000–6,500; bar 2,000–5,000. Office 150–200 SF/employee. Warehouse per user. |
| Readiness | No | Second-gen preferred; convertible accepted with cost stated; pads only if user mentions build-to-suit |
| Lease budget | No | Derived: occupancy-cost target × expected annual revenue ÷ 12; if no revenue plan, show occupancy cost as $/mo and $/SF and let the reader judge |
| Expected revenue (restaurants) | No, but ask if the user wants the occupancy % screen | $350–500/SF/yr for QSR/fast-casual; $300–450 full-service; state the figure used |
| Occupancy-cost floor | No | ≤ 8% of revenue passes; 8–10% caution; > 10% fail (base + NNN + utilities) |
| Buy budget | No | Under $5M; owner-user default financing SBA 504, 10% down |
| Sub-markets | No | Whole city; group results by sub-market (e.g. Little Rock: Downtown/River Market, Midtown/Heights/Hillcrest, West LR/Chenal, SW LR, North Little Rock/Argenta) |
| Parking | No | Restaurants: ≥ 1 space / 100 SF dining or ~10 / 1,000 SF total; flag anything below |
| Drive-thru | Only if concept implies it | Not required |
| Term | No | 5-yr initial + options for lease; note sublease remaining term |
| Timing | No | Open within 6–9 months; pads and shells usually miss this |
