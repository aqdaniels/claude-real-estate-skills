# Trade-off analysis: subject vs new build, with 1/5/10-year returns

Every report includes this section. It answers two questions the rest of the report doesn't: *would the same money do better in new construction?* and *what does the position look like at years 1, 5 and 10?*

## Part A — Subject vs new build

Compare the subject (as-is, or as-renovated if a rehab is planned) with building the equivalent property new — same unit count and mix (or same beds/sqft for a single-family home) in the same submarket, on purchased land or on the subject's own land if the honest answer is "tear down."

### Research (add to the parallel search batch)

- `<city> new construction cost per square foot <year>` and `<city> garden apartment construction cost per unit <year>` — prefer local contractor/appraiser sources over national indexes; note whether the figure is hard cost only
- `<submarket> land for sale zoned <multifamily/residential>` — $/acre or $/buildable unit
- `<city> new construction <beds> bedroom rent` / new-build sale comps — the rent or price premium new gets over 1980s–2000s stock
- Local incentives that only apply to new build or gut rehab: Opportunity Zone status, Restoration Tax Abatement (Louisiana), PILOTs, LIHTC/HANO partnership, impact fee waivers
- Permitting and construction timeline for the jurisdiction

### Build the comparison table

| | Subject (buy [+ rehab]) | New build |
|---|---|---|
| Land / acquisition | purchase price | land cost (or $0 if using subject's site, but then add demolition) |
| Hard cost | rehab | $/sf × GSF, or $/unit × units |
| Soft cost (A&E, permits, fees, financing, contingency) | ~10–15% of rehab | 20–25% of hard cost |
| Carry to stabilization | months × (interest + taxes + insurance + security) | months × same, longer period |
| **All-in cost** | | |
| Cost per unit / per sq ft | | |
| Time to stabilization | rehab + lease-up | entitlement + build + lease-up (typically 24–36 mo) |
| Stabilized rent (avg/unit or per home) | market comps for renovated stock | new-build premium, usually 15–30% over renovated Class C |
| Expense ratio | from Income & Expenses section | 5–10 points lower (new roofs, HVAC, plumbing; lower insurance; warranty period) |
| Stabilized NOI | | |
| Exit cap / value | cap for renovated stock | 50–100 bps tighter for new product |
| **Stabilized value** | | |
| **Equity created (value − all-in)** | | |
| Risk profile | condition unknowns, tenant-in-place, insurance on old stock | entitlement, construction cost overruns, longer carry, interest-rate exposure |

For a single-family home the same table compares buying the subject against buying or building a comparable new home: price vs cost-to-build, insurance (new-build FORTIFIED roofs price materially lower on the Gulf Coast), maintenance (0.5% vs 1–1.5%), resale premium, and warranty.

State the verdict of the comparison in one sentence: which option produces more equity per dollar of cost, and which produces more equity per month of time. They are often different answers.

## Part B — 1 / 5 / 10-year returns and equity

Run a simple annual projection for the subject and for the new-build alternative. Owner-occupant single-family reports run it for the subject only, against renting.

### Inputs (show them)

| Input | Default |
|---|---|
| Rent growth | neighborhood trend from research; default 2% |
| Expense growth | 3% |
| Appreciation / cap-rate at exit | hold exit cap flat; value = NOI ÷ cap. For single-family, use the neighborhood's 5-yr price trend; default 2% |
| Loan | the financing scenario already in the report; amortize normally (bridge → refi in the value-add case) |
| Selling costs at exit | 6–8% (only in the "if sold" line) |
| Reinvestment of cash flow | none — cash flow is taken, not compounded |

### Output table

| Year | NOI (or net housing cost) | Cash flow after debt service | Cumulative cash flow | Property value | Loan balance | **Equity** | Equity created since purchase | **Cash-on-cash** | **Total return** (cum. cash flow + equity gain) ÷ cash invested | **Equity multiple** |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | | |
| 5 | | | | | | | | | | |
| 10 | | | | | | | | | | |

One row block for the subject, one for the new build. Include a simple IRR only if a sale at year 5 or 10 is assumed — say which.

For an owner-occupant, replace NOI with "owning cost vs renting": cumulative principal paydown + appreciation − (ownership cost − comparable rent) is the equity-vs-renting line, and the 1/5/10 view shows when owning overtakes renting.

### Reading it

- Year 1 is almost always negative or flat for value-add and new build; say so, so the reader doesn't misread a bad year 1 as a bad deal.
- Year 5 is where the two paths usually diverge: new build has higher equity if costs held, the subject has higher cash-on-cash if the rehab was cheap.
- Year 10 shows whether the older asset's rising CapEx (roofs, HVAC second cycle) erodes the gap.
- Flag the crossover year, if any, where the new build's equity passes the subject's.

Every projected number is `est`. Keep the section to one comparison table, one returns table, and three or four sentences of interpretation.
